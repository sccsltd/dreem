# Hardware images

This directory contains Dreem 2 mainboard photographs, closeups of relevant components and test points, and the FCC internal-construction-photo exhibit.

## Original camera-label mapping

The contact sheet still prints the camera's original `IMG_*.JPG` labels. They map to the descriptive filenames as follows:

| Contact-sheet label | Descriptive file |
| --- | --- |
| `IMG_3676.JPG` | `dreem-2-mainboard-module-lower-closeup.jpg` |
| `IMG_3677.JPG` | `dreem-2-mainboard-module-side-overview.jpg` |
| `IMG_3678.JPG` | `dreem-2-mainboard-module-upper-closeup.jpg` |
| `IMG_3679.JPG` | `dreem-2-mainboard-imx6ull-emcp-side-overview.jpg` |
| `IMG_3680.JPG` | `dreem-2-mainboard-imx6ull-pmic-emcp-closeup.jpg` |
| `IMG_3681.JPG` | `dreem-2-mainboard-imx6ull-usb-closeup.jpg` |
| `IMG_3682.JPG` | `dreem-2-mainboard-imx6ull-board-connector-closeup.jpg` |
| `IMG_3683.JPG` | `dreem-2-mainboard-usb-corner-closeup.jpg` |

`dreem-2-mainboard-photo-contact-sheet.jpg` combines those eight camera images. The other JPEGs are higher-resolution crops centered on the board connector, eMCP, i.MX6ULL, USB area, and nearby test points.

`dreem-2-fcc-internal-construction-photos.pdf` is the seven-page Bureau Veritas FCC construction-photo exhibit for the Dreem 2.
